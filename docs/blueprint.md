# **App Name**: CampusCheck

## Core Features:

- Student Profile Management: An intuitive interface to register new students, including their name, unique fingerprint ID (`id_huella`), and guardian's phone number (`telefono_tutor`). Allows for editing and viewing existing student details.
- Live Attendance Stream: A real-time dashboard displaying student entry and exit events as they are recorded by the Raspberry Pi, showing student name, event type (entry/exit), and precise timestamp.
- Comprehensive Attendance History: An interface to browse, search, and filter historical attendance records, allowing detailed review by student, specific date ranges, or event type for reporting.
- WhatsApp Notification Status & Logs: A dashboard component to confirm the operational status of the WhatsApp notification system and view a log of recent notification attempts and their success status, leveraging the Whaticket API.

## Style Guidelines:

- Primary color: A deep and professional blue (#2E5DB8), reflecting reliability and a focused digital presence, appropriate for an educational environment.
- Background color: A very light, clean blue-gray (#E0E4EB), ensuring high readability for data and providing a sense of openness and modernity.
- Accent color: A vivid cyan (#3CC3DD), chosen for its strong contrast against the primary blue, drawing attention to calls-to-action and key indicators, while maintaining a clean tech aesthetic.
- All text will use 'Inter', a grotesque-style sans-serif, providing excellent readability and a neutral, objective, and modern feel suitable for a data-driven application.
- Clean, line-based icons that clearly represent actions and data points related to student management, attendance tracking, and communication, ensuring visual clarity.
- A structured and organized layout, featuring clear data tables, intuitive forms for student registration, and responsive components for seamless access across various devices.
- Subtle and functional animations for navigation, form submissions, and real-time data updates, enhancing user experience without distractions and reinforcing efficiency.
